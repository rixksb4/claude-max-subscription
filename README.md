## 先把「开通」拆成三道独立的坎

很多人以为订阅失败是「支付问题」，其实支付只是最后一环。真正会卡住的是三个独立关卡，任何一关没过，前面全白做。

**第一关：地区与网络。** Anthropic 的服务对支持地区有要求，中国大陆不在其列。Claude Code 的中文文档本身也直说了：默认配置下需要能访问 claude.ai 和 Anthropic API 端点，在国内网络环境下这些端点可能无法直接访问 [2]。这不是「慢一点」的问题，是连不上。

**第二关：账号身份。** 注册环节可能要求手机号验证，+86 号码在这个流程里通常走不通，你需要一个海外号码。

**第三关：支付。** 官方只收美元，支付宝、微信、国内银行发行的双币卡都不在支持范围内。这是绝大多数人最终放弃自建路线的直接原因。

关键细节在这里：**Max 目前仅提供月度订阅**，官网也只有网页端的价格档位，移动端价格会因应用平台而不同 [1]。这意味着网上流传的「买美区 Apple 礼品卡、在 App 里订阅」那套做法，主要验证过的是 Pro 档位；Max 档在移动端价格多少、是否开放，得你自己打开 App 确认。把礼品卡方案当成能开 Max 的通用解法，是会踩空的。

## 5x 还是 20x：先判断你的用量，再决定付多少钱

$100 和 $200 之间差了一倍，很容易选错。

官方对 5x / 20x 的解释是「单会话可用额度相对 Pro 的倍数」，5x 和 20x 指的都是这个倍数关系，并不是固定的 token 配额 [1]。另外 Max 除了每 5 小时重置一次的单会话限制，还有一个跨模型的每周上限，且每周重置时间是跟着账号走的，你什么时候开始订阅不影响这个重置点。

按实际场景判断更实用：

- 你每天用 Claude 写东西、读长文档、偶尔跑几段代码，Pro 的额度其实够，没必要直接上 Max。
- 你把 Claude Code 当主力开发工具，一天里有大段时间挂在上面，Pro 经常在半天内就见底，那 Max 5x 是更合理的那一档。
- 你在跑完整的 agent 工作流、长上下文、多任务并行，几乎不想算额度，才轮到 Max 20x。

从 Pro 升到 Max 是按剩余周期比例补差价的，Max 5x 升 20x 同理。所以先用 5x，不够再补差价升上去，比一上来就买 20x 稳妥。

顺便说一句官方不会说的话：**Anthropic 明确表示不对任何付费方案提供标准折扣**，包括 Max 5x 和 20x [1]。所以你在任何地方看到「Claude Max 官方折扣码」「六折开 Max」这类宣传，都可以直接划走。第三方平台的减免来自它们自己的服务费让利，不是官方折扣。

## 下单前必须问清楚的三件事

代订阅这件事，钱付出去之后你能拿回多少，取决于规则而不是取决于客服态度。以下三点在下单前确认清楚：

- **退款比例和手续费。** 社区记录里出现过这样的条款：如果官方退款给平台，平台退还约 71.5%，再另收一笔几美元的服务费；如果官方不退款，平台也不垫付。也就是说，平台在「不封号」时赚差价，在「封号」时赚的是退款里的那部分。这不是黑，这是它公开写在规则里的商业模式，但你得知道自己在赌什么。
- **质保范围。** 「封号质保」和「掉订阅质保」是两件事。有的平台写的是封号后需你自己向官方申诉，申诉成功才退款，申诉不成功不赔。把这条读清楚，比看任何评价都有用。
- **你自己要承担的部分。** 账号本身要干净。如果注册时用的 IP 就飘忽不定、登录设备频繁更换，订阅开上去照样会被风控带走。支付方解决了付款，解决不了账号历史。

另外，平台自身的服务状态也会波动。有用户反馈过某段时间 Claude 档位显示售罄、充不进去的情况，遇到这种直接等或者退款，别着急换号重下。

## 常见问题

**能用支付宝或微信直接付给 Claude 官方吗？**
不能。官方只收美元，支付宝、微信、国内卡都不在支持范围内，这也是第三方平台存在的原因。

**Max 有年付吗？**
目前没有，官方说明 Max 仅提供月度订阅，年付折扣只存在于 Pro 档 [1]。

**开了 Max，用 Claude Code 还需要另外充 API 吗？**
需要区分两件事。Pro 和 Max 订阅本身包含 Claude Code 的使用额度，日常开发够用；但如果你是用 API Key 直接调用模型，那是按量计费的另一套账，两者独立计费。用订阅额度跑 Claude Code，就不需要在 Console 里另外预充值。

**开了之后多久能用？**
平台侧通常几十分钟内完成开通，实际以订单状态为准。开通后建议先确认一下订阅是否已经出现在 Claude 账号的设置页里，再开始跑任务。

**Pro 和 Max 选哪个？**
先看你会不会在日常工作中撞到 Pro 的限制。如果一周都撞不到，Max 的 $80 到 $180 差价对你没有意义。
